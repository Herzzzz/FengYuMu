# 枫语幕 macOS 原生版

这是 Windows v3.2.3 的原生 macOS 移植工程。它复用仓库根目录的完整 TSV 词库，使用 ScreenCaptureKit 截取游戏窗口、Vision 做英文 OCR、独立透明 `NSPanel` 覆盖中文，不读取或修改游戏进程。

## 支持范围

- Apple 芯片（arm64），当前验收基准为 MacBook Air M4。
- macOS 26.6.2 或以上；不支持 Intel Mac 和旧 macOS。
- Xcode 26 / Swift 5.9 语言模式或以上。

## 已实现链路

- F8 单次截图翻译与隐藏；三档翻译范围。
- ScreenCaptureKit 只接受前台且名称明确匹配冒险岛的窗口，随后固定窗口 ID 与进程 ID；不会自动转向浏览器等其他前台应用。
- Vision 英文 OCR、词库命中、动态数字不覆盖、透明点击穿透覆盖层。
- 默认关闭的持续翻译。
- F9 重找游戏窗口，F10 显示 AI 悬浮窗，菜单栏常驻入口。
- 用户自己的联网 AI Key；Key 保存在 macOS 钥匙串。
- AI 悬浮框中译英并复制、实时聊天 OCR 去重、系统低血量/低蓝量提示过滤；关闭 AI 面板会停止监听。
- 无开发者账号的安全复制助手：保留 macOS 隔离检查，不在用户电脑上重签，更新失败时回滚旧版；支持未来 Developer ID 签名和公证。

## 在真实 Mac 上构建

```zsh
cd macos
zsh scripts/build-release.sh
```

脚本会先运行核心测试和真实冒险岛截图的 Vision OCR 自测，再以 arm64 Release 模式构建、组装 `.app`、验证代码签名并生成 DMG 和 SHA-256。没有 `DEVELOPER_ID_APPLICATION` 时生成本机临时签名内测包；设置该变量时使用 Developer ID 正式签名。

## 发布前必须完成的实机验收

1. 全新普通用户账户中运行“首次安装”，确认无需终端和管理员密码。
2. 首次权限、拒绝后重开权限、应用重启三条路径都测试。
3. 游戏窗口化、全屏、Retina 默认缩放分别执行 F8/F9/F10。
4. 任务列表、任务详情、技能详情、人物属性、设置页、NPC 对话逐类对照。
5. 持续翻译运行 30 分钟，确认无明显闪烁、重复标签或内存持续增长。
6. AI 手动中译英与实时聊天各测试豆包和一个 OpenAI 兼容接口。
7. 在无 Xcode 的干净 Mac 上安装最终 DMG，核对版本、词库数量和 SHA-256。

Windows 环境不能替代以上实机验收。只有这些项目全部通过，才能将内测标记改为正式可用。
