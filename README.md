# 枫语幕

枫语幕是一个面向 Windows 的《冒险岛国际怀旧服》屏幕翻译覆盖工具。

程序启动后把词库载入内存并在托盘后台等待。按下呼出快捷键时，它优先只截取当前前台窗口的客户区，对画面放大并增强文字对比度，再使用英语 Windows OCR 识别原文，只把词库命中的内容用中文覆盖到原位置；按下缩回快捷键后立即撤下覆盖层。

## 使用

1. 从 Releases 下载最新版压缩包。
2. 保持 `枫语幕.exe` 与 `枫语幕词库.tsv` 在同一目录。
3. 双击 `枫语幕.exe`。程序默认进入托盘后台。
4. 默认 `F8` 呼出翻译，`F9` 缩回后台。
5. 按 F8 前先点击游戏窗口，让冒险岛保持在最前面；程序不会翻译被其他窗口遮挡的内容。

每次按 F8 都会重新截取当前画面、重新识别并重新匹配。F9 会立即清空本次覆盖；再次按 F8 不会复用任何历史截图或历史翻译结果，因此角色移动、装备悬浮框改变后不会拿旧位置覆盖。

托盘显示为“枫语幕 v2.1.0”。托盘右键提供：打开并更改词库、更改快捷键、AI 实时聊天翻译、同步AI词库、退出；双击托盘图标可直接打开实时聊天翻译。

### v2.1.0 界面分区与当前怀旧服技能库

- 人物属性面板增加结构化定位，即使经典像素字体把 `NAME/ATTACK/CRIT. DAMAGE` 识别错，也能在正确字段位置显示中文标签。
- 装备详情增加深色面板红字专用复核；任务日志继续按任务代码匹配完整正文。
- 每次 F8 在截图前强制清空旧覆盖并等待桌面合成完成，不会把上一次的中文框再次识别进去。
- 收录 Henesys.gg 当前怀旧服技能快照：261 个技能、3,804 条等级效果；全部技能名和说明均已中文化并载入内存。
- 四张用户实图回归：技能约 0.60 秒、任务约 0.66 秒、人物属性＋技能约 0.96 秒、被旧覆盖遮挡的装备录像截图约 1.23 秒；均低于 2 秒。

- 玩家名永不翻译；最近六条消息仅提供语境，英文照抄会自动触发强制中文重试。
- “怀旧服-聊天短语”中的社区审核译文优先于 AI，可直接在词库编辑器中继续完善。

- 1440p 等高分辨率画面先进行低负载全屏识别；未发现详情时才在时间预算允许的情况下补做鼠标附近的小区域识别。每次 F8 仍使用全新截图。

## v1.4.1 AI 实时聊天翻译与低配置优化

实时AI翻译功能来自 @奇怪小鸭。

- 新增置顶小窗。点击“框选/调整游戏聊天区”，倒计时内切回游戏；随后拖动并缩放橙色框，精确选择玩家自己的聊天区域。
- 开启实时翻译后，每约 1 秒重新截取该区域，只翻译新出现的聊天行，不复用旧截图；同一时刻最多运行一个识别/翻译任务。
- 默认不进行持续截图。担心兼容性或电脑较旧的玩家可点击“单次识别翻译（兼容模式）”，每次只截取并识别一次；实时轮询必须由玩家主动开启。
- 支持中文、英语、日语、韩语；也可以在输入框手动完成四语互译并复制译文。程序不会代替玩家向游戏发送文字。
- 玩家名硬保护：程序先分层拆出 `[17:17]` 时间戳、频道标记、发言玩家名和冒号，这些内容不会发送给本地或在线 AI；同一会话中再次提到已识别玩家名时也会先占位、翻译后原样还原。
- 翻译采用本机 Qwen3 AI，并把当前句子命中的冒险岛词条作为强制术语，兼顾聊天语境和游戏固定译名。
- 首次使用 AI 功能时，十年前的普通电脑建议安装 1.7B 超轻模型（约 1.1 GB）；也可选择 4B 轻量模型（约 2.5 GB）或 8B 高质量模型（约 5 GB）。下载完成后永久离线运行，无账号、API 和调用次数限制。
- 安装窗口提供“检查并更新现有模型”：同时核对 Qwen3 模型与 llama.cpp 显卡运行库；没有变化不会重复下载。更新使用临时文件并支持续传，失败时保留当前可用模型。
- 模型和 llama.cpp Vulkan 运行库保存到 `枫语幕.exe` 同目录下自动创建的 `模型` 文件夹，不安装 Python 或 Ollama，整个程序目录可直接移动或通过 QQ 分享。
- 模型下载完成后会自动执行一次“知识初始化”：校验并读取资料站整理内容及当前 `枫语幕词库.tsv`，建立词库指纹和分类清单。翻译时只把与当前句子相关的术语送入模型，不把整份词库塞进上下文。
- GGUF 是只读量化推理模型，因此这里不进行耗时、伤硬盘且需要高配置的权重训练；采用可随词库更新的本地检索知识库。词库未变化时只检查 SHA-256，不重复初始化；修改或导入词库后自动增量刷新。
- 初始化记录保存在 `模型\枫语幕知识初始化.json`，只有几百字节，不额外下载训练框架，也不会持续占用 CPU/GPU。
- 启动程序、保存/导入词库后会自动同步AI知识；托盘和AI窗口也提供“同步AI词库”。同步只重新载入术语和轻量索引，不重新下载模型，正在运行的AI从下一句话开始采用新词库。
- 模型安装器固定使用 TLS 1.2、跟随 Windows 系统代理，模型按 ModelScope 国内源、国内镜像、Hugging Face 依次尝试，并对临时网络故障自动重试三次；下载中断后可以续传。正式包预带 Vulkan 运行库，首次安装无需连接 GitHub。
- 不针对某一张显卡写死：Vulkan 会自动识别 AMD、NVIDIA、Intel 显卡。默认只卸载少量模型层到显卡，失败后逐级降低占用，最终自动回退 CPU；AI 进程使用较低优先级、最多两个 CPU 线程、单任务推理和较小上下文，尽量给游戏保留资源。
- 打开翻译窗口不会立刻加载大模型；第一次真正翻译时才载入。停止实时翻译后模型不再计算，并保留 5 分钟快速待命；持续空闲后自动释放模型内存。
- AI 译文可以加入“纠错候选”。候选不会直接污染正式词库，只有玩家在审核窗口确认后才写入 TSV 并重新载入内存。
- `枫语幕纠错候选.tsv` 是很小的待审核文件，可以和正式词库一起通过 QQ 群交换；不使用 AI 功能时不会生成。
- 可选“联网 AI 复核”：默认关闭且不弹配置窗口。玩家自愿使用时，可填写任何 OpenAI 兼容的 HTTPS 接口、模型名和密钥。本地 AI 先给出译文，联网 AI 只负责复核；断网、额度用完或接口失败时自动保留本地结果。
- 在线复核产生的改译同样只能进入待审核队列，不会自动覆盖词库。密钥由 Windows 当前账户加密保存在注册表，不会写入 TSV 或 QQ 分享包。
- 本项目不预置第三方密钥，也不承诺第三方在线服务永久免费；永久免费的基础能力始终是本地 Qwen3。

- 同任务代码能够直接采用中文资料的内容优先保留；没有可靠中文对应的英文对白使用现有 NPC、地图、怪物、道具和技能译名统一术语后翻译，并在编辑页标明来源。

- 截图中先确认存在任务窗口、任务标题或已收录的任务整句，才启用任务词库；普通装备、怪物、道具和技能窗口不会调用任务句子。
- 确认任务后优先在同一任务代码内匹配最长整句，避免把对白拆成多个一词多义的普通词条。
- 资料站不能可靠一一对应的对白没有自动硬配。玩家可在任务编辑页补充或修正，保存后立即重新载入内存。

## 识别改进

- 只截取按下快捷键时的前台窗口客户区，避免同时翻译旁边的聊天软件。
- AI窗口提供“框选/调整游戏聊天区”：倒计时内切回游戏后会显示截图和一个橙色选框。可拖动框体，也可拖拽四边或四角调整长宽，按确定保存。
- 这始终是同一个共享区域：框内只交给AI聊天翻译读取，同时F8主翻译完全跳过；框外继续处理装备、技能、任务、地图和NPC。不会分别保存两个容易混淆的框。
- 区域同时保存屏幕坐标和相对游戏窗口的比例；游戏移动或改变分辨率后，下一次F8会按当前游戏窗口更新同一个AI区域。玩家改变聊天栏布局后也可随时重新框选。
- 识别前自动把小字号画面放大到合适尺寸，并适度增强文字对比度。
- 国际服固定优先使用英语 OCR；系统没有英语 OCR 时才回退到系统语言。
- OCR 坐标会按放大比例换算回原窗口位置，中文覆盖仍对齐原文。
- 在一秒预算内自适应执行彩色增强、灰度高对比和更高分辨率三种 OCR；合并各轮独有的可靠词库命中，较慢电脑会自动减少轮数。
- 3,178 个物品、装备、技能、怪物和 NPC 的真实资料站图标已压缩为 64 位指纹，随文字词库一次性载入内存。
- 同英文名但中文不同的造型、颜色或职业版本必须同时通过文字与图标核对，不会只凭名字随机覆盖。
- 文字完全命中时直接翻译；文字有少量 OCR 错误时，只检查文字左侧附近的小图标并与候选文字共同确认，避免全屏遍历图标。

建议使用窗口化或无边框窗口。独占全屏可能不显示桌面覆盖层。

## 词库格式

`枫语幕词库.tsv` 是 UTF-8 TSV 文本：

```text
英文原文<Tab>中文翻译<Tab>分类#资料ID<Tab>可选图标指纹或来源<Tab>任务接取地图/区域
```

示例：

```text
Snail	蜗牛	怀旧服-怪物#2
```

程序启动时一次性把常规索引、按任务代码隔离的任务索引和图标指纹载入内存，待机期间不反复读取硬盘。原有 F8/F9 功能完全离线；只有玩家主动一键安装 AI 模型时才下载文件。修改后可在词库窗口点击“保存并载入内存”，无需重启。

当前 174 个任务均带有接取地图/区域分类，共 15 组。任务词库页可以按地图筛选；新增任务和双击编辑任务时也能填写或修改该分类。

## 安全边界

程序不读取或修改游戏内存，不注入或挂钩游戏进程，不修改游戏文件，也不模拟鼠标键盘输入。它只使用前台窗口截图、英语系统 OCR、全局快捷键和独立透明窗口。

程序不使用隐藏覆盖层的防截图标记。兼容模式只在玩家主动点击或按快捷键时进行单次截图；实时聊天轮询默认关闭。

任何第三方防作弊系统都可能误报，本项目无法承诺绝对不会误报。使用前请自行确认所在服务器规则。

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\src\build.ps1
```
