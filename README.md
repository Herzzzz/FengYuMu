# 枫语幕

枫语幕是一个面向 Windows 的《冒险岛国际怀旧服》屏幕翻译覆盖工具。

程序启动后把词库载入内存并在托盘后台等待。按下呼出快捷键时，它截取当前显示器画面，使用 Windows 系统 OCR 识别英文，只把词库命中的内容用中文覆盖到原位置；按下缩回快捷键后立即撤下覆盖层。

## 使用

1. 从 Releases 下载最新版压缩包。
2. 保持 `枫语幕.exe` 与 `枫语幕词库.tsv` 在同一目录。
3. 双击 `枫语幕.exe`。程序默认进入托盘后台。
4. 默认 `F8` 呼出翻译，`F9` 缩回后台。

托盘右键只有三个功能：打开并更改词库、更改快捷键、退出。

建议使用窗口化或无边框窗口。独占全屏可能不显示桌面覆盖层。

## 词库 1.0

词库 1.0 专门针对国际怀旧服当前内容整理，共 3,379 条（2026-08-12 数据快照）：

- 道具：2,525
- 地图：302
- 任务：165
- NPC：150
- 技能：81
- 怪物：72
- 常见界面：58
- 职业：15
- 地区：11

资料按同一游戏数据 ID 对齐英文名和简体中文名。明显无关的现代服内容、GM专用物品、无英文名以及同英文对应多个中文且无法从屏幕区分的歧义项不会进入自动覆盖词库。

## 词库格式

`枫语幕词库.tsv` 是 UTF-8 TSV 文本：

```text
英文原文<Tab>中文翻译<Tab>分类#资料ID
```

示例：

```text
Snail	蜗牛	怀旧服-怪物#2
```

程序启动时一次性载入词库。修改后可在词库窗口点击“保存并载入内存”，无需重启。

请阅读 [CONTRIBUTING.md](CONTRIBUTING.md)。提交时尽量保留第三列的资料 ID，以便核验。

词库名称对照主要参考：

- [冒险岛国际怀旧服 GCW 小册子](https://mxdgcw.dvg.cn/)：当前 GCW 内容范围、英文名、简体中文名与资料 ID。

## 安全边界

程序不读取或修改游戏内存，不注入或挂钩游戏进程，不修改游戏文件，也不模拟鼠标键盘输入。它只使用 Windows 截图、系统 OCR、全局快捷键和独立透明窗口。

任何第三方防作弊系统都可能误报，本项目无法承诺绝对不会误报。使用前请自行确认所在服务器规则。

## 构建

在 Windows PowerShell 中运行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\src\build.ps1
```

编译依赖 Windows 自带的 .NET Framework C# 编译器和 Windows OCR 组件。
