## 安装与使用

下载 `FengYuMu_v4.0.zip`，完整解压到新目录，保留 EXE 和全部三份 TSV，双击 `枫语幕.exe`。默认使用 Windows 自带 OCR，无需下载识别模型。需要 Windows 10 1903+ / Windows 11、.NET Framework 4.8 和英语 OCR 语言支持。

启动时将词库载入内存并建立索引。进入游戏后按 F8 识别并显示，再按清除；下一次开启重新捕获。识别结果统一匹配、擦除原字并显示中文。任务、装备和技能共用通用规则；没有指定任务、道具、职业或技能的运行时修补分支。AI 实时聊天需要自行配置服务商。

从 3.x 或早期测试版升级，推荐完整解压新版，并在词库选项确认使用新版词库。在线更新保留活动主词库，官方新版另存供合并；旧更新器可能遗漏补充词库。

## 本次改进

- 技能简介、当前等级和下一级效果分别匹配并同时显示，通用效果词汇保留本次识别数值。
- 任务正文支持无物品图标布局和滚动后的正文片段；灰底所需物品栏只翻名词，保留图标和数量。
- 装备属性共享字段匹配；人物属性按字段格显示，职业组和转职名称统一查词库。
- 聊天按原文字颜色保存频道，译文保留原分类；选框内部整块可拖动，首页卡片随窗口宽度居中。
- 聊天空闲检测间隔由 140ms 调为 117ms，频率约提高 20%。

## 验证与构建

r15 基线通过 44 组、758 项受控逻辑、词库及像素回放检查，包括 3,804 条技能等级效果、35 个职业/转职组简介路径，以及 36 张技能图的 41 个提示框。正式版另检查品牌、更新安装文件、包哈希和源码构建一致性。受控测试不等于所有服务器、所有职业的实机翻译成功率；Windows OCR、游戏滚动与颜色表现仍取决于本机环境。

Windows 原生构建需要 Visual Studio 2022 / Build Tools 的 .NET 桌面生成工具；脚本自动下载并校验固定版本的 .NET 4.8 与 Windows SDK 引用包。执行：`powershell -NoProfile -ExecutionPolicy Bypass -File src/build.ps1`。发布工作流构建 Windows 版本、运行升级与文件事务检查，再生成附带 SHA-256 的下载包。测试中的旧版编号表示回归来源；原始用户截图和运行日志不随发布包分发。

macOS 源码沿用原有分支能力，本次发布与验证范围为 Windows。许可证见 [LICENSE](LICENSE)。
