## 不能写死成两种颜色

旧版冒险岛聊天至少区分普通、好友、组队、家族、联盟、悄悄话；此外还有系统/公告、普通喇叭和超级喇叭。不同客户端版本及玩家设置可能改变具体 RGB，因此 v3.0 的规则是：

1. 每条消息从玩家当前游戏画面采样字体色，不用固定颜色替代来源颜色。
2. 只对有充分实帧证据的蓝底普通喇叭、粉底超级喇叭做背景分类。
3. 蓝底与粉底分别保存原背景和原字体色；普通消息不添加背景。
4. 没有实帧证据的来源不根据名称或近似颜色臆测分类。

参考：Nexon 聊天指南说明聊天字体颜色可以由玩家设置；旧版聊天资料列出普通白、组队浅紫、好友橙、家族深紫、联盟浅绿、悄悄话深绿等来源色。具体实现仍以目标视频和用户实际画面采样为准。
