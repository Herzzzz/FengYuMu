# 词库 1.5 说明

生成日期：2026-08-12

词库收录能用于屏幕 OCR 匹配的英文原文和对应简体中文名称。v1.3 补全当前 GCW 范围内所有任务的说明和对白；常规词库与任务词库保持独立逻辑索引，仍共用一个 TSV 文件。

第四列为可选图标指纹或任务来源说明，第五列用于任务名称条目的接取地图/区域。程序启动时连同文字索引一次性读入内存；旧格式和社区自定义条目仍可正常使用。

## 收录原则

- 以国际怀旧服当前数据库 ID 为内容白名单。
- 怪物、地图、任务和道具优先直接使用 GCW 中英文名称字段。
- NPC 英文缺失时，使用 MapleStory Classic 专站按相同 NPC ID 补齐。
- 技能仅收录 GCW 当前存在且中英文名称不同的技能。
- 删除纯中文、空英文、`Unknown`、GM专用道具以及无法消除歧义的重复英文名。
- 中文经过繁体转简体规范化。

## 当前数量

总计 6,584 条。任务列表共174个，其中包含四个职业共16个当前转职任务环节；任务内容包含174条完整说明、1,143条完整对白和1,879条对白分句，空白任务为0。

174个任务已全部补齐接取地图/区域，分为15组；任务词库界面可按地图筛选和编辑。

其中 2,828 条带有真实资料图标指纹：物品/装备、技能、怪物和 NPC。界面属性等没有独立游戏图标的条目继续使用文字识别。

生成时的源数据规模为：道具 3,763、怪物 89、任务 174、地图 304、NPC 188、技能 108。未进入最终词库的记录主要是无可用英文名、中英文相同、GM专用，或英文重名导致无法可靠覆盖。

## 已知边界

- OCR 识别不到的文字无法命中词库。
- 同任务代码可可靠采用中文资料的内容优先保留；其余英文对白使用现有冒险岛名称词库统一术语后翻译，并在第四列标明来源或翻译方式。
- “新增任务”可建立资料库尚未收录的任务；QQ群导入导出会连同任务代码、说明、对白和来源一起保留。
- 同一英文名称对应多个不同中文对象时，为防止错误覆盖，该名称会被排除。
- 任务句子只在识别到任务窗口、任务标题或已收录任务整句时启用，不与装备、怪物、道具、技能的普通词条混用。
