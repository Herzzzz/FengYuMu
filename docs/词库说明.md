# 词库 2.0 说明

生成日期：2026-08-13

词库收录能用于屏幕 OCR 匹配的英文原文和对应简体中文名称。v1.3 补全当前 GCW 范围内所有任务的说明和对白；常规词库与任务词库保持独立逻辑索引，仍共用一个 TSV 文件。

第四列为可选图标指纹或任务来源说明，第五列用于任务名称条目的接取地图/区域。程序启动时连同文字索引一次性读入内存；旧格式和社区自定义条目仍可正常使用。

## 收录原则

- 以国际怀旧服当前数据库 ID 为内容白名单。
- 怪物、地图、任务和道具优先直接使用 GCW 中英文名称字段。
- NPC 英文缺失时，使用 MapleStory Classic 专站按相同 NPC ID 补齐。
- 技能名称仅收录 GCW 当前存在且中英文名称不同的技能；技能、装备和物品的固定详情说明按同一资料 ID 单独索引。
- 删除纯中文、空英文、`Unknown`、GM专用道具以及无法消除歧义的重复英文名。
- 中文经过繁体转简体规范化。

## 当前数量

总计 8,189 条。任务列表共174个，其中包含四个职业共16个当前转职任务环节；任务内容包含174条完整说明、1,143条完整对白和1,879条对白分句，空白任务为0。

174个任务已全部补齐接取地图/区域，分为15组；任务词库界面可按地图筛选和编辑。

其中 3,178 条带有真实资料图标指纹：物品/装备、技能、怪物和 NPC。当前可翻译的物品2,814个、怪物83个、技能93个均已按资料ID配对图标；NPC索引覆盖188个资料ID。界面属性等没有独立游戏图标的条目继续使用文字识别。

详情索引新增323条技能说明（覆盖93个当前技能）和771条装备/物品说明。另有217条角色属性、背包、任务助手、装备条件、技能等级等固定界面词。详情说明不进入普通短词索引；多行OCR会优先匹配整段内容，动态等级、攻击力、属性值和数量仍保留在原画面。

词库编辑器的常规页分为界面、地图/NPC、怪物、职业技能、装备、消耗品、任务/其他物品、详情说明和图标资源；职业技能还能继续按职业筛选。任务名称、说明和对白仍在独立任务页按任务代码与接取地图编辑。

同英文名但对应不同中文的造型、颜色或职业版本不会只凭文字直接替换，必须由文字与图标共同确认。这样既保留全部资料ID，也避免同名条目串译。

生成时的源数据规模为：道具 3,763、怪物 89、任务 174、地图 304、NPC 188、技能 108。所有具备有效且不同中英文名称的资料ID均已收录；未进入自动覆盖词库的记录是无可用英文名、中英文相同或GM专用内容。

## 已知边界

- OCR 识别不到的文字无法命中词库。
- 详情长句允许少量OCR漏字，但仅在一个资料ID明显胜出时覆盖；相近候选无法区分时不会强制翻译。
- 同任务代码可可靠采用中文资料的内容优先保留；其余英文对白使用现有冒险岛名称词库统一术语后翻译，并在第四列标明来源或翻译方式。
- “新增任务”可建立资料库尚未收录的任务；QQ群导入导出会连同任务代码、说明、对白和来源一起保留。
- 同一英文名称对应多个不同中文对象时，为防止错误覆盖，该名称会被排除。
- 任务句子只在识别到任务窗口、任务标题或已收录任务整句时启用，不与装备、怪物、道具、技能的普通词条混用。
