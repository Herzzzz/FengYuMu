## 五、源码结构导读（给后续 GPT-6.1 复核）

### 1. 入口与翻译主链

- `src/MapleOverlay.cs`：程序入口、主 Overlay 窗口、F8/F9/F10、截图请求取消、词库加载、OCR 行匹配、任务/技能/装备/角色/玩家菜单结构化标签、置信度合并、标签绘制、托盘和基准模式。复核重点是 `ShowTranslationAsync`、`LabelConfidencePolicy`、`MergeLabels`、结构化面板构建和 `OverlayPaintSafety`。
- `src/MapleWindowTracker.cs`：捕获前的安全边界。按进程名、窗口标题、类名、可见性、拥有者和客户区尺寸锁定 MapleStory；`TryGetCaptureBounds` 不允许全桌面回退；只做 `PROCESS_QUERY_LIMITED_INFORMATION` 级别的只读身份查询。
- `src/SceneRecognition.cs`：视觉场景层。包含浅色/深色面板检测、设置页、角色属性、玩家右键菜单、动态视觉证据，以及 `PanelContextPolicy` 的任务上下文隔离。

### 2. OCR、翻译和术语层

- `src/StrongOcrClient.cs`：可选外部增强 OCR helper 的安全封装。通过临时文件/JSON 交互，有限时、坏输出和进程失败安全降级；不改变默认 Windows OCR 路径。
- `src/TranslationTerminology.cs`：术语最长匹配、占位符、数字/等级/百分比保护和安全恢复。
- `src/OfflineChat.cs`：聊天 OCR 区域、离线模型客户端、在线 AI 客户端、供应商预设、Key 的 Windows 当前账户加密保存、聊天队列、分类过滤、第三页与 AI 浮窗。`TranslatePanelAsync` 仅接收面板 OCR 文本，不接收截图。
- `src/OutboundChatIntent.cs`：出站聊天意图和“翻译并复制”策略；程序不会自动向游戏发送文字。
- `枫语幕词库.tsv`：UTF-8 TSV 游戏词库，包含界面、地图/NPC、怪物、技能、装备、物品、任务 ID、任务地图和详情说明；运行时建立常规、任务 ID 和图标/上下文索引。

### 3. UI、更新和设备层

- `src/SimpleForms.cs`：三页主界面、蓝白卡片、圆角按钮、返回键、DPI 布局、聊天分类栏、AI 设置、词库编辑器、快捷键和托盘相关窗体。`FlatPillButton` 用于无打光频道栏，`BlueGlassButton`/`BlueGlassPanel` 用于主界面蓝白卡片体系。
