枫语幕 v3.0｜简明使用说明
============================

一、快速开始

1. 保持“枫语幕.exe”和“枫语幕词库.tsv”在同一文件夹。
2. 双击“枫语幕.exe”，程序会先显示主界面；确认“已就绪”后点击“缩到托盘，返回游戏”。
3. 切回冒险岛窗口，再按 F8 开启中文覆盖。
4. 再按一次 F8 会关闭当前覆盖；F9 只用于自动对齐游戏聊天框。

每次用 F8 从关闭切换到开启，都会重新截图和识别，不会复用上一次的画面或结果；识别过程中再按 F8 也会取消本轮结果。
建议使用窗口化或无边框窗口；独占全屏可能无法显示覆盖层。

主界面的“翻译范围”滑动条有三档：

- 兼容最大：保留全部识别范围和 v2.3 稳定路径。
- 推荐均衡：优先详情框和对话，兼顾可靠面板；日常推荐。
- 精简最小：最多复核最高优先级的两类区域，适合较老电脑。

优先顺序为：详情框 > 对话框内 > 对话框外 > 当前界面。高优先级区域不存在时，后面的区域会自动前移。选择会立即生效并自动保存。

持续自动翻译（默认关闭）：

1. 在主界面勾选“持续自动翻译（检测到游戏面板即显示）”。
2. 缩到托盘并切回游戏。人物属性、装备/物品详情、技能、任务、NPC 对话或商店等面板出现后，会自动显示译文，无需按 F8。
3. 无面板时程序只做快速场景探测并逐步降低频率，不会反复运行昂贵的高分辨率 OCR。
4. F8 仍可随时手动开启、关闭或重新截图；F9 只重新探测聊天框位置，不会触发截屏翻译。

“持续自动翻译”以功能、精度和响应速度为优先，适合配置较好的电脑；较老电脑建议使用“范围最小”，或关闭持续模式继续使用 F8。

AI实时翻译独立浮窗：

1. 从托盘打开“AI实时聊天翻译”，点击“开始实时翻译”后独立浮窗会直接出现，不需要额外勾选。该窗口只显示玩家聊天的 AI 译文，F8 仍在游戏原位置显示词库译文。
2. 浮窗采用接近游戏聊天框的半透明无边框样式；拖动顶部可移动，拖动四边或四角可自由改成长条、方框或竖框，位置和大小会自动记住。
3. 普通、好友、组队、家族、联盟、悄悄话、系统和公告会沿用游戏画面实际采样到的字体色，不写死为某组 RGB。
4. 浅蓝整行底色是普通喇叭，浅粉整行底色是超级喇叭；浮窗分别保留对应字体色和底色，方便与游戏原消息对应。
5. AI 实时翻译主窗口右上角的红叉只隐藏设置和历史界面，后台监听与独立浮窗继续运行；只有主动点击“停止实时翻译”才会停止监听。
6. 点独立浮窗自己的红叉，只是暂时把浮窗藏起来；有新消息也不会突然弹回。想重新显示时，右键托盘图标，点“重新显示AI翻译悬浮窗”。双击托盘图标只负责打开主界面。

联网AI怎么开（不用租服务器）：

1. 打开“AI实时聊天翻译”，点“联网AI设置”。
2. 不知道选谁就用“豆包 2.0 Lite”；DeepSeek V4 Flash 是快速备选；想先免费试可以选智谱 GLM-4-Flash。
3. 点“打开申请页面”，跟着网页注册、开通对应模型并创建 API Key。
4. 把“API Key 管理”页给你的整串 Key 粘进去，点“保存并测试”。不要填账号的 Access Key 或 Secret Key。成功后以后直接点“开始实时翻译”就行。
5. 测试失败时，窗口会直接说明是 Key 不对、模型没开通、额度不足还是网络问题，不用自己猜。
6. 不用常开网页，也不用租服务器。豆包、DeepSeek 的费用从你自己的服务商账号扣，智谱免费模型受对方的额度和限速规则影响。

联网模式会直接翻译，不会先让本地模型机翻一遍。每条聊天都会自动带上“冒险岛怀旧服玩家”语境和本句命中的词库术语，只在窗口里显示最终译文；联网失败才启动离线备用模型。API Key 用 Windows 当前账户加密保存在本机，不会写进词库或分享包。

一键更新怎么用：

1. 打开主界面，点最下面的“一键更新”，剩下的不用自己逐个下载。
2. 枫语幕会从 GitHub 正式发布页下载最新版，并做两次 SHA-256 校验。发现文件没变化就会直接告诉你已经是最新。
3. 真有更新时，会先把当前的 EXE、词库和说明备份到程序旁边的“更新备份”，然后自动重启替换。
4. 下载断了、文件校验不对或替换失败，都不会硬着头皮覆盖；程序会继续用原来的版本，已经开始替换的也会自动回退。
5. 版本名字仍是 v3.0 也没关系：只要发布包内容换过，一键更新会按文件内容识别，不靠版本名猜。

键盘和手柄快捷键：

1. 点击主界面的“快捷键”。
2. 键盘“翻译开/关”和“自动对齐聊天框”可分别设置，默认 F8 / F9。
3. 手柄“翻译开/关”和“隐藏翻译”也可分别设置，每项可选一个键，或再选第二个键组成双键同时按。
4. 点击“保存并立即生效”。键盘和手柄两套设置互不覆盖，都可以随时使用。

手柄默认不绑定。支持 Xbox/XInput 手柄，以及经 Steam Input 映射为 XInput 的手柄。按住单键或组合只会触发一次，完整松开后才能再次触发。程序只读取手柄按键状态，不会向游戏发送按键；未设置手柄绑定时不会启动手柄轮询。


二、鼠标悬停详情

把鼠标放到技能、装备或物品上，等待详情框出现后再按 F8。
程序会翻译名称、固定说明和属性标签，并保留当前等级、攻击力、数量、卷轴次数等数值。

人物属性窗口会按界面结构完整覆盖固定字段；把鼠标放到暴击率、移动速度等属性上时，较矮的属性说明框也会整句翻译。
任务助手中的“3/10 Snail”等进度会保留实时数量，只翻译已确认的怪物或道具名。

技能、装备和物品详情使用独立索引。无法可靠区分相近对象时，程序会选择不翻译，避免套用错误说明。


三、玩家聊天翻译

玩家聊天区域只交给 AI 翻译，F8 普通翻译不会覆盖该区域。

首次设置：

1. 正常切回冒险岛并按 F9；程序会根据底部玩家聊天行自动对齐聊天框，识别不到可靠聊天行时使用经典布局。
2. 托盘右键选择“AI实时聊天翻译”，即可直接使用同一区域。
3. 如果自动区域不符合自己的聊天栏布局，点击“框选/调整游戏聊天区”，在倒计时内切回游戏。
4. 拖动橙色框选中完整聊天区域；拖动边缘或四角可调整大小。
5. 按 Enter 或点击“确定区域”保存，按 Esc 取消。手动区域一经保存，F9 自动对齐也永远不会覆盖。

这个框同时决定：

- AI需要读取的聊天区域。
- F8必须跳过的聊天区域。

玩家名、时间戳和频道标记不会交给 AI 翻译。程序也不会自动向游戏发送文字。


四、修改和分享词库

托盘右键选择“打开并更改词库”。

常规词库可按以下分页查看：

- 界面
- 地图/NPC
- 怪物
- 职业技能（可继续按职业筛选）
- 装备
- 消耗品
- 任务/其他物品
- 详情说明
- 图标资源

任务词库单独按任务代码和接取地图管理。双击任务可修改任务名、说明和完整对白，也可以新增任务。

修改后点击“保存并载入内存”即可生效，无需重启。
通过“导出QQ群分享包”和“导入群友词库”可与群友共同完善翻译。


五、离线 AI 模型

AI聊天翻译第一次使用时需要安装模型：

- 1.7B 超轻模型：旧电脑推荐，约 1.1 GB。
- 4B 轻量模型：翻译更好，约 2.5 GB。
- 8B 高质量模型：配置较高时使用，约 5 GB。

模型保存在程序旁边的“模型”文件夹，下载一次后可以永久离线使用，不需要账号或 API。
程序会自动尝试 AMD、NVIDIA、Intel 显卡；显卡不可用时自动回退 CPU。AI会按处理器规模自动使用 2 至 10 个线程；大多数处理器会保留两个逻辑核心给游戏和系统。停止翻译并空闲五分钟后会释放模型内存。

未配置联网 AI 时，打开 AI 翻译面板会预热离线模型；已配置联网 AI 时不会白白加载本地大模型。聊天区每 140ms 检查一次新消息。本机离线 8B 模型从完全停止到首句的历史实测约 4.4 秒，模型就绪后单句可到数百毫秒；联网模式还会受服务商和网络延迟影响。

模型安装后会读取当前词库建立轻量知识索引。词库修改后会在打开 AI 功能时自动同步，不需要重新下载模型，也不需要再找单独的同步按钮。

实时AI翻译功能来自 @奇怪小鸭。
联网AI完全可选；不配置也不影响 F8 截图覆盖、词库翻译和离线AI。


六、托盘功能

- 打开主界面
- 打开并更改词库
- 更改快捷键
- AI实时聊天翻译
- 重新显示AI翻译悬浮窗
- 退出

双击托盘图标可重新打开主界面。

如果任务管理器里能看到枫语幕、但托盘图标消失，再次双击“枫语幕.exe”即可唤回已有程序并重新显示主界面。程序不会重复启动第二个后台实例；Windows 任务栏重启后也会自动恢复托盘图标。


七、常见问题

没有出现翻译：

- 确认按 F8 前冒险岛处于最前面。
- 确认系统安装了英语 OCR。
- 等详情框完全出现后再按 F8。
- 字体过小或画面移动时，先停住画面再试。

翻译位置不对：

- F8 翻译框位置不对时，再按 F8 关闭，等画面稳定后重新按 F8 截图。
- AI 聊天框位置不对时，按 F9 自动重探测；仍不合适时在 AI 窗口手动框选。
- 游戏分辨率或窗口位置改变后会按保存比例自动同步；手动框选过的区域不会被 F9 覆盖。

模型下载失败：

- 程序会保留已下载部分，再次点击可续传。
- 下载按国内源、镜像和 Hugging Face 依次尝试，不强制要求 VPN。


八、配置要求

正式支持的最低配置：

- Windows 10/11 64 位，系统已安装英语 OCR。
- 四核处理器、16GB 内存、独立显卡、SSD、1280×720。
- CPU 回退只用于显卡启动失败时保留基本可用性，不属于正式支持配置。

推荐配置：

- 六核及以上处理器、32GB 内存、支持 Vulkan 的独立显卡、SSD。
- 1920×1080 至 2560×1440。

实测环境为 Windows 11、i5-12490F、32GB。本轮无面板探测平均 73ms、最大 121ms；最重技能面板连续识别平均 1,403ms、最大 1,526ms，峰值私有内存约 230MB。不同分辨率、OCR 语言包和后台负载会影响速度。

以上只针对截图词库翻译。离线 AI 聊天模型还需约 1.1GB、2.5GB 或 5GB 磁盘空间。


九、安全说明

枫语幕只使用窗口截图、Windows OCR、全局快捷键和独立透明覆盖层。
程序不会读取或修改游戏内存，不注入游戏进程，不修改游戏文件，也不模拟鼠标键盘输入。

任何第三方防作弊系统都可能误报，无法保证绝对不会误报；使用前请确认所在服务器规则。
